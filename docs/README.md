# Design and review records

The dated design/plan documents (Markdown and PDF) preserve the original planning-stage scope and proposed steps. Statements there about awaiting execution, a future private repository, or not yet publishing are historical, not current instructions or repository status. The owner subsequently authorized this public repository.

The scorecard records aesthetic/user acceptance separately from technical QA; no acceptance score has been invented. Current delivered geometry, checks and limitations are summarized in the root README and `qa/independent-review.json`. RTDS-specific models are still future work.
