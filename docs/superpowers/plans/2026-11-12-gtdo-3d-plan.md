# GTDO V2 3D Output Wiring Lab Implementation Plan

**Goal:** Turn presentation pages 15–17 into a hands-on output circuit with a real GTDO V2 model, original DC supply and resistive load equipment.

**Architecture:** Keep a pure electrical teaching-state module separate from original Three.js equipment geometry and a lifecycle-managed scene. Route into the selected GTDO hardware teaching area using the established gallery contract. Do not change existing input/power lessons.

**Constraints:** Sources remain private. Reuse published GTDO V2 model and documented terminal labels; no invented mating certification. Show logic zero as high impedance. Ideal current estimates are not measured values or a hardware safety certification. No real equipment control.

## Tasks and acceptance
- [ ] Pure state tests first: correct four-wire circuit, high/high-Z states, missing return, direct output supply conflict, invalid values, power interlock, reset and page changes.
- [ ] Geometry tests first: original supply/load, published board unchanged, CH1/V+/V− anchors found from metadata, all cable endpoints meet terminals, only complete current loops animate.
- [ ] UI + route tests first: page 15/16/17 deep links, same hardware selection, keyboard wiring, old input routes unchanged, hidden scene stops, back/forward preserves safe power state, retry after rendering failure.
- [ ] Implement source-verified circuit and scene; mobile layout and reduced-motion behavior.
- [ ] Independent source/code review; run all unit tests, build, targeted browser tests and inspect desktop/mobile screenshots. Parent runs full frozen browser and publishing pipeline.

## Review focus
1. High-Z is a driver state, not an unconditional zero-voltage output.
2. V2 group/driver limits must not be inferred from V1 conditions.
3. A load drawing current requires both supply reference and return conductors.
4. Page history must not bypass power-off wiring lockout.
5. Hidden/reduced-motion/context-lost scenes must not animate or retain live listeners after disposal.
