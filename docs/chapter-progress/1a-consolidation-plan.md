# 1A 部件辨识与章节覆盖收束计划

## 范围与设计
沿用现有 Three.js 与硬件上下文，不重做模型。把 PDF 21–23、27–28、33–34 的源清晰内容合成一个部件参考区：前部 2U/4U 空白面板、侧板、门的紧固方式不可混用；接地仅陈述位置；电源组件仅提供名称/制造商/型号识别，不生成接线或替换建议。使用原生选择器、即时文字反馈和可折叠事实表，不以无证据动画暗示真实结构。
