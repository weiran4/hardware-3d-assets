# 2A 专用 GTSYNC 对端与补偿条件

## 本轮小计划
继续 NovaCor 2.0 接线主课，不启动 GTSYNC 整章。以原生选择控件呈现 NovaCor 专用 GTSYNC 口到 GTSYNCv2 的 GT 口或旧 GTSYNC 的 GT1。复用真实 NovaCor 接口定位；不虚构不存在的 GTSYNC 3D 模型。相较新建抽象动画，有限检查器更适合接口/版本错误和未知状态，且不会暗示实际通信时序。

来源已独立页图交叉核对：NovaCor 2.0 PDF71–72；GTSYNCv2修订20260603，PDF471、481–482、487；旧GTSYNC修订20240924，PDF491、503–504、509–510。两个对端版本分开标记修订。链路是GT光纤，不是BNC/ST时源输入、以太网、GBH或IRC，不能进入普通GTI/O卡链。

## 实施与验收
1. 测试先失败，增加纯函数检查版本、主机/对端端口、介质和必要离线配置假设。未知输入不能获得匹配结论；正常及错误预设可恢复。
2. 如来源确认，加入 GTSYNC→NovaCor skew 配置算术：750 ns + 5 ns/m，允许设置0–999 ns。必须标明这是来源推荐的补偿设定，不是实测端到端延时或最长可用光纤承诺，超出设定范围仅提示核对，不截断数值。
3. 集成既有2A硬件上下文，保持其它硬件隐藏、深链接/前进后退、键盘、移动端和无WebGL可读。
4. 独立来源/代码复核，全单测/build及浏览器回归。检查桌面、手机与原有真实模型/PiP截图；本地若受限，使用现有CI实际渲染证据。
5. 不改变发布工作流。确认精确提交 verify→deploy→smoke-live 与匿名资产一致后才算上线。

## 边界
离线假设不修改真实设备。没有时源电平接线、PTP主从/交换机配置、时间质量表、许可操作或未知针脚。标为2A完善中，不声称整章手册或GTSYNC专章完成。私有手册与截图不进入公开仓库。
