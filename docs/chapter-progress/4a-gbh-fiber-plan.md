# 4A GBH V3：协议、光纤与IRC版本

计划：在既有GBH详情区域增加NovaCor↔GBH V3同步光路检查器；独立于案例分组，按两端协议、介质、光路长度及IRC版本检查。只使用有来源的边界，不计算延时，不推断混代或针脚。

来源：PDF200–201（GBH V3修订20250910），交叉核对PDF543–544。A配1mm POF最大30m；B配1mm POF最大50m、200µm HCS最大100m。超过30m且使用IRC时需要V2。两端协议应一致。PDF544旧固件前提RTFPGA0356+不泛化为各代固件编号。PDF200一处“少于30m”与最大值表述不同，按同页上限及PDF543表的30m最大值；PDF543 HCS单位疑点由PDF201的200µm交叉确认。

验收：先新增边界/错误/未知输入单测并见失败；实现工具与正常/错误示例；独立来源及代码复核；全单测和build，桌面/手机/失败恢复浏览器测试及截图，既有GLB/PiP/隐藏动画/路由回归；精确提交verify→deploy→smoke-live及匿名线上核验后才算发布。

范围：仅NovaCor↔GBH V3。NovaCor直连A最大20m，不能套用本工具30m；旧硬件/混代不适用。A+HCS无确认表，输出待核对。未确认固件、光端部件或系统配置不因长度合格获得现场接线许可。保留全章部分覆盖，机械/维护不阻碍核心课程接续。
