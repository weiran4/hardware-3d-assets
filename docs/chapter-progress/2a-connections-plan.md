# 2A NovaCor 2.0 接口选择与 I/O 链检查计划

## 范围
以修订20250916的2A章PDF65–105为基准，本轮核心来源PDF71–74。为已选NovaCor 2.0提供接口用途/线缆类别选择及有序GT I/O卡链规则检查。保留前面板模拟监视与真实GLB接口定位。只检查来源明确的类别与组合，不宣称真实设备接线已经安全或可运行。

- [x] 新模块隔离纯规则与UI；测试正常链、错端口、独占卡、超过8张、GTAI与其他输入混链、GTDI时敏顺序、未知输入和重置。
- [x] 2A只随NovaCor2.0选择显示；新增深链接，保留旧模拟课链接与前进后退。切硬件停止隐藏动画。
- [ ] 桌面/手机、键盘、无WebGL、真实3D、重复切换及旧课程回归。
- [ ] 独立审查、全部单测/build、精确提交verify→deploy→smoke-live、实际截图与匿名资源核验。

## 本轮边界
不增加安装/温度/长度工具，不跨用NovaCor1.0或Light，不购买许可、不操作真实设备。输入链时敏位置是定性建议；无已确认端到端延时数值，不把采样/更新时间或概念动画当作延时。2A仍为接线基础版，机间/同步拓扑与特定I/O卡电气、针脚和应用约束另行核对，不声称整章完成。

实现前已用缺失模块/路由测试确认失败，再通过219项单测和build。浏览器包含128个用例；本地Chromium受运行环境限制无法启动，发布前验证与匿名线上验证由原有CI门槛执行，未声称本地视觉通过。
