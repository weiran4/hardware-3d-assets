# 2A NovaCor 2.0 机间数据与同步连接计划

## 设计与范围
目标是让学习者分别选择同步链路和机间数据链路，识别两者不能替代。沿用现有 NovaCor 2.0 章节和原生控件，新增独立纯检查器与三组原创连接路径示意。相比新建抽象3D拓扑，路径示意不虚构多机精确布线；相比静态说明，检查器可演练错配和恢复。用户已授权自主逐章制作并要求聚焦接线，不增加长度/安装工具。

来源：NovaCor 2.0 修订20250916，PDF80–82、97–100。两机无hub须GBH直连和IRC数据直连，P2P开启；使用GBH hub时P2P关闭，数据可按本章类别采用直接IRC或IRC switch。三台起需要GBH hub，超过七台不能依赖六个IRC通道直接连接类别；不据此推断全网容量、网状/环状布线或真实时延。

## 边界
P2P地址配置以离线“已核对”假设输入，不收集真实IP。机间传输未提供端到端延时，不能从距离或动画速度计算。光缆/协议/GBHv3细节留相应专章，不能把点对点规则套在hub链路。这里是2A连接核心增量，不声称整章全部覆盖。
